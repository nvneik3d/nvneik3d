### Projects

**[origin](https://github.com/nvneik3d/Origin)**
An evolving cell simulation. Every cell runs its own small neural network, then eats, splits, mutates and dies inside a virtual dish. Watch it live at [origindish.net](https://origindish.net). The simulation and website are open source under MIT.

**[BlendSCII](https://github.com/nvneik3d/BlendSCII)**
A free Blender add-on that renders scenes as ASCII art, with a live viewport preview. Build a scene, and it comes out as characters.
